# doc-tools

文書処理のスクリプトをスキルに同梱した Claude Code プラグイン（旧 `my-tools-no-install` のうち文書処理の部分）。

対応する CLI を `tools/` からインストールする必要はなく、プラグイン（または個別スキル）をよそへ移しても動く。

- [skills/doc-transcription/](skills/doc-transcription/) — 文書の書き起こし（同梱の uv プロジェクトで動く）

一覧は生成カタログ [skills/CATALOG.md](skills/CATALOG.md)。スキルの置き方は [web-lookup](../web-lookup/README.md) と同じ。
