# logs/ について

`discovering-skills`スキル利用時に、エージェントがタスクごとにどうスキルを組み合わせたかを`SKILL_USAGE.md`へ1行追記していく場所。リポジトリ全体の`.gitignore`にある`logs/`ルールの対象だが、ここだけは`.gitignore`側で明示的に例外化してgit管理下に置いている（ユーザーが履歴として見直せるようにするため）。

エージェントは`SKILL_USAGE.md`への追記のみ行う。整理・重複排除・「同じ組み合わせが繰り返されているのでパターン化する」といった判断はユーザーが都度見直して行う（エージェント側で自発的に行わない）。

## SKILL_USAGE.mdのフォーマット

- パターンに合致した場合: `- YYYY-MM-DD: <タスクの一言要約> → パターン合致: <patterns/*.mdのファイル名>`
- 合致しなかった場合（skill-searchで見つけた組み合わせ、または手探りで選んだ組み合わせ）: `- YYYY-MM-DD: <タスクの一言要約> → 未パターン化: <スキル名, スキル名, ...>`

## ユーザーによる見直し

`SKILL_USAGE.md`で同じ組み合わせ（特に「未パターン化」のもの）が繰り返し出てきたら、`../patterns/`配下に新しいパターンファイルを追記し、`../BEST_PRACTICES.md`のパターン一覧に登録する。昇格させたエントリはログから削除してよい。
