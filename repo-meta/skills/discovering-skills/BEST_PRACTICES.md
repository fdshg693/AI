# discovering-skills: よくあるタスクパターン早見表

`skill-search`エージェントを毎回呼ばずに済むよう、このリポジトリでよく発生するタスク形状と、その際に組み合わせるべきスキル群をあらかじめまとめた早見表。SKILL.md本体の手順2（skill-searchエージェント呼び出し）より前に確認する。

## 使い方

1. タスクがここに載っているパターンのいずれかに合致するか確認する。合致すれば該当パターンファイル（`patterns/*.md`）を読み、指示されたスキルをTODOに組み込む（SKILL.md本体の手順4以降と同じ要領）。
2. 合致するパターンがない、またはパターンに載っているスキルだけでは不足していると感じたら、通常通り`skill-search`エージェントに検索を依頼する（SKILL.md本体の手順2）。
3. パターンに載っているスキル名が実在するかは、使う前にGlobで一発確認する（リネーム・削除されている可能性があるため）。
4. 同じ形のタスクが繰り返し発生していると気づいたら、このファイルと対応するパターンファイルを追記して育てる。

## パターン一覧

| パターン                 | 該当するタスクの特徴                                                                           | 詳細                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| スキル新規作成・改修     | SKILL.mdを新規に書く/既存を直す/frontmatterのmetaフィールドを触る                              | [patterns/skill-authoring.md](patterns/skill-authoring.md)             |
| 他AIツールへの横展開     | claude-plugins向けに作った機能をcursor/codex/copilot/cline/antigravity等にも展開する           | [patterns/cross-tool-porting.md](patterns/cross-tool-porting.md)       |
| 外部ドキュメント調査     | Microsoft/Azure公式・ライブラリAPI・一般Web記事など外部情報を調べて実装/ドキュメントに反映する | [patterns/external-doc-research.md](patterns/external-doc-research.md) |
| リポジトリ内バッチAI処理 | 複数ファイルへ同一プロンプトを投げる/要約を永続化する等、繰り返しAI呼び出しが必要              | [patterns/batch-ai-processing.md](patterns/batch-ai-processing.md)     |

## 注意

- ここに載っているのは「よく発生する」パターンのみで網羅ではない。載っていない形のタスクは素直に`skill-search`へ進む。
- 1つのタスクが複数パターンにまたがることもある（例: 新規スキルを書いてから他ツールに横展開する）。その場合は該当パターンを両方読む。
- パターンファイルの粒度は「タスクの形」単位であり、個別スキルの使い方そのものは書かない（それは各スキルのSKILL.md本体の責務）。
