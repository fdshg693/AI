# ラフプラン作成時

要件や実装方針がまだ固まっていない複雑なタスクで、詳細プランを書く前に方針を書き殴るためのフェーズ。

- シンプルなタスク（[plan-writing.md](plan-writing.md) の「単一ファイルで完結」基準に収まるもの）ではラフプランは不要。直接、詳細プランを書く。
- 置き場所はプロジェクト用フォルダ配下の `rough/`（例: `.claude/plans/{project-name}/rough/*.md`）。
- 形式は自由。5点フォーマット（[plan-writing.md](plan-writing.md) 参照）に縛られない。比較検討中の案、迷っている点、未解決の疑問をそのまま書いてよい。
- 軽量なOKF frontmatterを付ける。詳細プラン側（`type: Plan`/`Plan Step`）とは別の3値のみを使う。

  | 値               | 意味                                                                             |
  | ---------------- | -------------------------------------------------------------------------------- |
  | `drafting`       | ラフプラン作成中                                                                 |
  | `ready-for-plan` | ラフプラン作成完了。詳細プランに移れる状態                                       |
  | `promoted`       | 詳細プランに着手した。ラフプランの役割はここで終わり、以降このstatusは更新しない |

- 方針が固まったら、ラフプランの内容を [plan-writing.md](plan-writing.md) のフォーマットに従って詳細プランとして整理する。ラフプランは下書きであり実装時の正としては扱わない — 実装に着手する前に必ず詳細プランへ変換すること。
- ラフプラン自体は削除必須ではなく、検討経緯の記録として `rough/` に残しておいてよい。
