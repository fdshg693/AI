## 決定事項・注意点／落とし穴

| 決定                                                                                                                                                                                                      | 理由                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `hooks-logging.md`は「詳細はwriting-hooksスキルへ」という誘導を一切書かず、該当する全節をこのファイル内に転記する                                                                                         | ユーザー指示「一部ドキュメントの委譲などは行わないこと」。`claude-logs-investigate`が現在行っている委譲（frontmatterコメントでの参照）は踏襲しない                                                                                                                                                                             |
| ログ仕込みテンプレートは、Step3で実際に動作確認できたものだけを載せる（ドキュメントの記述だけを根拠にした未検証のテンプレートは載せない）                                                                 | 「動くはず」ではなく「実際に動いた」テンプレートを載せることが、このスキルを「単なる参考ドキュメントに留めない」ための核心的な要件のため                                                                                                                                                                                       |
| Windows特有の罠の節は、Step3で実際に再現できたものを優先し、再現しなかった／確認できなかった項目はその旨を明記した上でドキュメント由来の情報として区別する                                                | 実地検証と伝聞情報を混同しないため。実装者が原因切り分け時にどちらの情報かを判断できるようにする                                                                                                                                                                                                                               |
| ログ仕込みテンプレートは全て「別ファイルのPythonスクリプト + exec form（`command: "python"` 固定、`args`配列でスクリプトパス/引数を渡す）」に統一し、シェルスクリプトやshell form文字列コマンドは使わない | ユーザー明示指示（可読性・トラブルの少なさ）。exec formはJSON入力・引数ともシェルのクォート処理を経由しないため、shell formで起きうるクォート/エスケープ由来のトラブルが構造的に発生しない。実地検証（出力に`'`・`"`を含むケースを含む）で問題なく動作することを確認済み。[00-overview.md](00-overview.md)の決定事項に追記済み |
