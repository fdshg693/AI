| 決定                                                                                                                                                                                             | 理由                                                                                          |

| Claude CLI分離テストの手順は、Step7で実際に動作確認したコマンドをそのまま載せる（ドキュメントの組み合わせ推測だけに基づく手順は載せない）                                                        | 「動くはず」ではなく「実際に動いた」手順を載せることが、このスキルの核心要件のため            |
