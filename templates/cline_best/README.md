# Cline ベストプラクティス

## 重要な Cline の特徴（ツールの更新に伴い、随時変更する）

- https://docs.cline.bot/features/subagents#how-it-works
  - サブエージェントは独立したコンテキストを持つ
    - 複雑なコンテキストを保持したまま作業はできず、必ずある程度独立したタスクに分割した上で呼び出す
  - ファイル編集・ブラウザ操作・MCPサーバー利用・ネストされたサブエージェント呼び出しなどを行えない
    - サブエージェントをネストしたい場合は、CLIによるエージェント呼び出しなどを経由して実現する
    - ファイル編集などを代わりに行うのでなく、読むべきファイルが絞れない/多すぎるなどの際の肩代わりの役割として使う
    - MCPサーバーによる拡張ができないため、hooksやスキル経由で能力を拡張する
