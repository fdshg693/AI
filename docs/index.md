# docs/ — このリポジトリの利用者向け OKF 知識バンドル

このリポジトリの成果物（プラグイン・スキル・CLI）を使う人向けの知識を、OKF (Open Knowledge Format) v0.2 の概念ドキュメントとしてまとめたバンドル。このリポジトリ自身の保守の規約・設計判断は [maintenance/docs](../maintenance/docs/index.md) にあり、このバンドルには含めない。
